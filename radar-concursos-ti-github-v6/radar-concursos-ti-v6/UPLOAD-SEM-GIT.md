# Enviar o projeto ao GitHub sem instalar Git

Repositório: https://github.com/osmarrcs/radar-concursos-ti

1. Extraia o arquivo ZIP.
2. Entre no repositório pelo navegador.
3. Clique em **Add file** e depois em **Upload files**.
4. Selecione o conteúdo de dentro da pasta extraída, não a pasta externa.
5. Confirme que estas pastas aparecem na raiz: `.github`, `data`, `docs` e `src`.
6. No campo de commit, escreva: `feat: versão inicial do portal`.
7. Clique em **Commit changes**.
8. Acesse **Settings → Pages**.
9. Em **Source**, selecione **GitHub Actions**.
10. Acesse **Actions → Publicar portal → Run workflow**.

Endereço esperado após a publicação:

https://osmarrcs.github.io/radar-concursos-ti/
